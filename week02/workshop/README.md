# Workshop สัปดาห์ที่ 2 (คลัง `git-practice`)

ทำตาม Workshop ที่ 2.1 ในหนังสือ บทที่ 2 แก้ไฟล์ `index.html` ในโฟลเดอร์นี้

- ดูผล: `https://<ชื่อผู้ใช้>.github.io/git-practice/week02/workshop/`
- `cp1/` หน้าหลังเปลี่ยนราคาลางสาดเป็น 70 บาท (จุดตรวจ 2 และผลสุดท้ายหลังย้อนกลับ)
- `cp2/` หน้าหลังคอมมิตที่ผิด (ทุเรียนหายไป) ใช้ฝึกย้อนกลับถ้าทำขั้นคอมมิตผิดไม่ทัน

## ใช้ไฟล์จุดตรวจเมื่อตามไม่ทัน
1. บน github.com เปิด `week02/workshop/cp1/index.html` (หรือ `cp2/`) แล้วกดปุ่มคัดลอก (Copy raw file) ข้างปุ่ม Raw
2. ใน github.dev เปิด `week02/workshop/index.html` กด Ctrl+A แล้ว Ctrl+V และ Ctrl+S
3. คอมมิตด้วยข้อความ เช่น `ใช้ไฟล์จุดตรวจ cp1` แล้วทำขั้นต่อไป
