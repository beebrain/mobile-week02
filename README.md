# คลังโค้ดตั้งต้น สัปดาห์ที่ 2 (`mobile-week02`)
วิชา 3603403 การเขียนโปรแกรมบนอุปกรณ์เคลื่อนที่ (Mobile Programming and Applications in Digital Business)

## วิธีใช้งานสำหรับนักศึกษา
1. กดปุ่มสีเขียว **Use this template** > **Create a new repository**
   - สำหรับฝึกในคาบบรรยาย (Workshop 2.1): ตั้งชื่อคลังว่า **`git-practice`**
   - สำหรับส่งใบงานที่ 2 (คาบปฏิบัติ): ตั้งชื่อคลังว่า **`mobile-week02`**
2. เลือกเป็น **Public** แล้วกด **Create repository**
3. เปิดใช้งาน **GitHub Pages** ที่เมนู **Settings** > **Pages** > เลือกกิ่ง **`main`** แล้วกด **Save**
4. กดปุ่มจุด (`.`) บนแป้นพิมพ์เพื่อเปิด **`github.dev`** แล้วแก้ไขไฟล์ตามขั้นตอนบนสไลด์:
   - โฟลเดอร์ [`week02/workshop/`](week02/workshop/) — สำหรับฝึก Workshop 2.1 ในคาบเรียน
   - ไฟล์ [`week02/index.html`](week02/index.html) — สำหรับทำใบงานที่ 2 (แก้ 3 TODO แยกคอมมิต 3 ครั้ง และฝึกย้อนกลับ 1 ครั้ง)
