# งานสัปดาห์ที่ 2: ใช้ Git ทำงานจริง (`mobile-week02`)
วิชา 3603403 การเขียนโปรแกรมบนอุปกรณ์เคลื่อนที่ (Mobile Programming and Applications in Digital Business)

## เริ่มต้น (ทำตามใบงานที่ 2)
1. กดปุ่มสีเขียว **Use this template** > **Create a new repository** ตั้งชื่อคลังว่า `mobile-week02` เลือก **Public** แล้วกด **Create repository**
2. เปิด GitHub Pages: **Settings** > **Pages** > Source **Deploy from a branch** > Branch `main` และ `/ (root)` > **Save**
3. เปิดเทอร์มินัล: ในคลังของตน กดปุ่ม **Code** > แท็บ **Codespaces** > **Create codespace on main**
   (ถ้ามีคำถาม *Do you trust the authors of the files in this folder?* ให้กด **Trust Folder & Continue**)
4. แก้ไฟล์ `week02/index.html` แล้วใช้ `git add` `git commit` `git push` ตามขั้นตอนในใบงาน

## ส่งงาน
ส่งลิงก์คลัง `https://github.com/<ชื่อผู้ใช้>/mobile-week02`
ผู้สอนตรวจจากประวัติคอมมิต ใช้ข้อความคอมมิตตามใบงานทุกตัวอักษร และห้ามแก้ไฟล์ด้วยปุ่มดินสอบนเว็บ
